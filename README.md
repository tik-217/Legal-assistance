# Правовая помощь

Первый экран и блок кейсов посадочной по военному праву на React 19. Исходный экран: `src/App.jsx`, стили: `src/styles.css`. Шапка, оффер, область фото команды, строка доверия и окно контактов оформлены как React-компоненты. Состояние окна контактов управляется React. Блок `src/Cases.jsx` содержит пять кейсов из раздела 2 структуры в Notion: ситуация, работа юристов, результат и специалисты. Кнопка после кейсов открывает ту же форму консультации.

Установка: `npm ci`. Локальная разработка: `npm run dev`. Сборка: `npm run build`. Просмотр собранной версии: `npm run preview`.

Vite собирает сайт в папку `dist`: HTML и оптимизированные файлы JavaScript и CSS. Для публикации разместите содержимое `dist` на статическом хостинге. Шрифт Manrope загружается из Google Fonts; при недоступности используется системный шрифт.

Первый экран приведен к разделу 1 структуры из Notion: исходные H1, подзаголовок и кнопка, строка доверия. На первом экране размещена предоставленная фотография. На телефоне все сведения из строки доверия видны.

В окне консультации есть форма с одним полем номера телефона. По запросу владельца отправка заявок пока не подключена: данные никуда не передаются, после заполнения формы и отметки согласия открывается демонстрационный экран «Спасибо» с адресом `?thank-you=1`. Это пока не подтверждение доставки заявки. Обновление страницы и кнопки браузера «Назад»/«Вперёд» поддерживаются; отдельная настройка маршрутов на статическом хостинге не требуется.

Рейтинг, число отзывов, награда, адрес и телефон взяты из исходного брифа в Notion. Перед запуском рекламы их нужно подтвердить. Знак компании служит временным логотипом.


В обеих формах есть обязательный чекбокс согласия, изначально не отмеченный. Он содержит ссылку на отдельную страницу `consent.html`; ссылка на `privacy.html` размещена отдельно под ним. Документы открываются из формы в новой вкладке, сохраняя введённый номер. Ссылки также доступны в подвале. Переменная `VITE_PRIVACY_POLICY_URL` больше не используется.

Третий блок — `src/Situations.jsx`: шесть ситуаций из Notion. Карточка открывает форму с выбранной темой и одним видимым полем телефона. Общие кнопки очищают выбранную тему. В навигации есть ссылка «С чем помогаем».

Четвёртый блок — `src/Reviews.jsx`: официальный iframe-виджет отзывов Яндекс Карт для организации 25885984565 и постоянная ссылка на все отзывы. Для виджета нужен доступ к Яндексу; он показывает общую подборку компании, а не отбор только военных дел. Отдельная подборка 4–5 согласованных отзывов из структуры Notion пока не подготовлена. Документация: https://www.yandex.ru/blog/mapsapi/vidzhet-otzyvov-dobavte-otzyvy-s-yandeks-kart-na-svoy-sayt

## Источник текстов

Маркетинговые тексты переносим дословно из https://app.notion.com/p/40242da791da81bc850bfb53ccdbb8e1. Исключения — конкретные правки, явно выбранные или написанные владельцем в чате (например, заголовок кейсов и единый текст кнопок). Не дописываем специализации, должности, результаты, сроки и факты на основе догадок. Если нужного текста нет в Notion, оставляем его незаполненным. Пометки «уточнить» не выдаём за подтверждённые факты. Удалённые по просьбе владельца контакты и WhatsApp не возвращаем. Отзывы отображаются официальным виджетом Яндекса, без переписывания.

В блоке команды вместо полос показаны нейтральные SVG-силуэты, выбранные владельцем как запасной вариант. Поиск по именам и сайту компании не позволил надёжно сопоставить доступные портреты с шестью специалистами. Сайт stav-law.ru на момент проверки возвращал 402; доступная архивная копия не содержала нужной команды. Изображения других людей не использованы.

Восьмой блок — `src/Pricing.jsx`: стоимость из раздела 8 Notion. По просьбе владельца показаны все три услуги и полный абзац об условиях оплаты и конкурентах, включая исходные пометки «[уточнить]».

Девятый блок — `src/Questions.jsx`: раскрывающийся список всех шести вопросов из раздела 9 Notion. По просьбе владельца ответы перенесены полностью, включая исходные пометки «[уточнить]», «[уточнить формулировку у клиента]» и «[уточнить ответ у клиента]».

Десятый блок — `src/ContactSection.jsx`: заключительная форма с заголовком и телефоном из раздела 10 Notion. По ранее принятым правкам оставлены одно поле телефона, обязательное согласие, единый текст кнопки и подсказка «Ответим в течение 30 минут»; адрес и WhatsApp не возвращены. Модальное окно и заключительный блок используют общий `src/ContactForm.jsx` с разными идентификаторами полей. Отправка остаётся демонстрационной: переход на `?thank-you=1`, без сохранения и передачи данных.

Подвал — `src/Footer.jsx`: повторяет существующие логотип, название, телефон и навигацию. В подвале размещены ссылки на обе юридические страницы. Подвал показан на посадочной; демонстрационный экран «Спасибо» сохранён без него.


## Юридические страницы

`privacy.html` и `consent.html` — отдельные входные HTML-файлы Vite. Они включаются в `dist` вместе с главной страницей и работают на статическом хостинге без перенаправлений SPA. Содержимое — `src/legal.jsx`, общие адреса ссылок — `src/legal-links.js`.

Документы подготовлены как проекты под фактическую демонстрационную форму. Прямой доступ к сайту фирмы на дату проверки возвращал HTTP 402. Адрес регистрации и email оператора не подтверждены. Адрес офиса из карт не назван юридическим адресом; email из стороннего справочника не перенесён как достоверный.

До подключения реальной отправки требуется заполнить пометки «[уточнить]»: адрес и email для обращений, срок хранения, обработчиков, место хранения данных, внешние сервисы и меры защиты. Необходимо обеспечить фиксацию согласия и его версии при реальном получении заявки. Текущая версия ничего не отправляет и не сохраняет. На юридических страницах видны статус проекта и описание демонстрационного режима; установлен `noindex`. Юридические тексты не являются согласованными документами клиента и должны быть проверены оператором перед использованием для реального сбора данных.
