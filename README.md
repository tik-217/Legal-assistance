# Правовая помощь

Первый экран посадочной по военному праву на React 19. Исходный экран: `src/App.jsx`, стили: `src/styles.css`. Шапка, оффер, область фото команды, строка доверия и окно контактов оформлены как React-компоненты. Состояние окна контактов управляется React.

Установка: `npm ci`. Локальная разработка: `npm run dev`. Сборка: `npm run build`. Просмотр собранной версии: `npm run preview`.

Vite собирает сайт в папку `dist`: HTML и оптимизированные файлы JavaScript и CSS. Для публикации разместите содержимое `dist` на статическом хостинге. Шрифт Manrope загружается из Google Fonts; при недоступности используется системный шрифт.

Первый экран приведен к разделу 1 структуры из Notion: исходные H1, подзаголовок и кнопка, строка доверия. На первом экране размещена предоставленная фотография. На телефоне все сведения из строки доверия видны.

В окне консультации есть форма с одним полем номера телефона. По запросу владельца отправка заявок пока не подключена: данные никуда не передаются, после заполнения формы и отметки согласия открывается демонстрационный экран «Спасибо» с адресом `?thank-you=1`. Это пока не подтверждение доставки заявки. Обновление страницы и кнопки браузера «Назад»/«Вперёд» поддерживаются; отдельная настройка маршрутов на статическом хостинге не требуется.

Рейтинг, число отзывов, награда, адрес и телефон взяты из исходного брифа в Notion. Перед запуском рекламы их нужно подтвердить. Знак компании служит временным логотипом.


В форме есть обязательный чекбокс согласия, изначально не отмеченный. Ссылка на утвержденную политику добавляется через `VITE_PRIVACY_POLICY_URL` в `.env.local`; после изменения требуется пересборка. Пока ссылка не задана, форма показывает только текст согласия.
